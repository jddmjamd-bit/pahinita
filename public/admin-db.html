♻️ Restaurar backup completo

Se reemplazará la base de datos actual y se perderán los cambios posteriores a la fecha del backup. La API quedará en mantenimiento durante la restauración.

El backup incluye usuarios y hashes, tokens, transacciones, saldos y ledger en el mismo archivo. Si PostgreSQL encuentra un error, revierte la restauración completa.

Selecciona un archivo .dump creado por este panel. Solo restaura archivos de confianza: un backup puede contener instrucciones SQL. El rol de conexión debe poder reemplazar los objetos de la base.
