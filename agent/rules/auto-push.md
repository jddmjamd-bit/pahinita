# Regla: auto push

Después de completar cualquier tarea que modifique archivos:
1. Ejecutá `git add .`
2. Generá un commit message descriptivo en español (convencional commits: feat:, fix:, chore:, etc.)
3. Ejecutá `git commit -m "<mensaje>"`
4. Ejecutá `git push origin <rama-actual>` (en el main porfa)

No pidas confirmación. Hacelo siempre.
